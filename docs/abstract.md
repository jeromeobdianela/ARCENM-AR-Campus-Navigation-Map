**Adviser:** Roland A. Calderon, DIT

## Abstract

This study developed ARCENM, an Augmented Reality-based Campus Exploration and Navigation Map for the Southern Luzon State University (SLSU) Tayabas Campus. The application helps visitors, new students, faculty, and employees find their way around the campus and access important information, including school profile, timeline, application requirements, and library e-resources.

Printed campus materials have limited space, can be damaged or lost, and cannot always hold complete information. ARCENM addresses this by delivering digital content through QR code scanning. When a code is scanned, the app displays an augmented 3D floor map showing the user's current location together with related information and links. This supports a paperless campus by reducing paper and ink costs and keeping information easy to update and access.

The application was built with Unity Engine (version 2022.3.20f1) and the Vuforia Engine for AR, using C# in Microsoft Visual Studio 2022, with Canva and Photopea for interface and asset design. It targets Android 8.0 (Oreo) and higher, and its core features work offline. The project followed an Agile development process covering planning, designing, construction, programming, testing, evaluation, deployment, data analysis, and maintenance.

Blackbox testing with 63 respondents checked installation, launching, performance, and graphics quality to find errors and improve usability. Acceptability was then evaluated by 20 respondents, including faculty and IT professionals, using a 4-point Likert scale based on ISO/IEC 25010 quality characteristics: functional suitability, performance efficiency, compatibility, usability, reliability, maintainability, and portability. The median and mode values averaged 4, corresponding to a rating of **Highly Acceptable**.

The results show that ARCENM is a usable and effective tool for campus exploration and information access.
